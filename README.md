# AI File Organiser

A Python tool that automatically organises files into categories based on file type and keyword-based classification.

## Features
- Automatically sorts files into folders (Images, Documents, Videos, Others)
- Handles duplicate file names
- Uses keyword matching to improve classification

## How to run
1. Run `python organiser.py`
2. Enter folder path
3. Files will be sorted automatically

## Tech
- Python
- File handling (os, shutil)
